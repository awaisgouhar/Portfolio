Personal portfolio website for **Awais Latif**, Network & Cybersecurity Infrastructure Specialist based in Mississauga, Ontario, Canada.

- **Hero** — headline, animated career stats (12+ years, 40+ Smart City deployments, 5,000+ nodes, 99.9% uptime)
- **About** — professional summary + contact fact card
- **Experience** — full timeline: My Zone AI → RUDA → Punjab Safe Cities Authority → Banu Mukhtar Contracting

- **Technical Skills** — grouped tech stack (routing/switching, security tooling, cloud, NOC, systems, governance, scripting, vendors)
- **Certifications** — 13 certifications + education
- **Contact** — email, phone, LinkedIn, location

## Tech

Pure HTML, CSS, and vanilla JavaScript — no frameworks, no build step, no external dependencies. Deploys anywhere as a static site (GitHub Pages ready).

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy (GitHub Pages)

Push to a GitHub repo, then enable Pages from the repo's Settings → Pages (deploy from `main` branch, root folder).
